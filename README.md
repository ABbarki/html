# website for dripora coffee shop using javascript pyhon sql

#### Description:
Dripora is a full-stack web application for an artisan specialty coffee shop based in Setif, Algeria. Built using HTML5, modern CSS3, JavaScript, Node.js, Express, and SQLite, the platform serves as both a brand storefront and an interactive customer experience. Key features include an editorial landing page with a categorized menu, a coffee culture journal, a customer feedback submission system integrated with an SQLite database (feedback.db), and "Dripora Bot" — an AI-powered barista assistant built using the Google Gemini API that can answer questions and recommend beverages according to the café's actual menu.
